# My Chinsali visual asset credits

The home-page image feature uses locally stored copies so the static site works without third-party image requests.

- `assets/chinsali-map.webp` and `assets/favicon.webp`: adapted from [Chinsali town & district location map](https://commons.wikimedia.org/wiki/File:Chinsali_town_district_location.PNG), created by Rexparry sydney from a public-domain source. The source page marks the work public domain. The favicon is a resized, letterboxed WebP adaptation.
- `assets/chinsali-town.jpeg`: image published with [Chinsali resident hails development](https://www.lusakatimes.com/2026/10/07/chinsali-resident-hails-development/) by Lusaka Times. The site should confirm editorial image reuse permission before production launch.
- `assets/chinsali-market.jpg`: thumbnail for [Chinsali New Market Grappling With Poor Sanitation](https://www.youtube.com/watch?v=ymO1lu345Gc), published by Diamond TV Zambia. The site should confirm image reuse permission before production launch.
- `assets/lubwa-mission.jpg`: Lubwa Mission image surfaced with [Top Soil: Chinsali and the making of the Zambian nation](https://eliasmunshya.org/2024/08/19/top-soil-chinsali-and-the-making-of-the-zambian-nation/) by Rev. Dr. Elias Munshya. The site should confirm editorial image reuse permission before production launch.
- `assets/chipoma-falls.jpg`: Chipoma Falls image surfaced through the [Chipoma Falls visitor listing](https://www.tripadvisor.com/Attraction_Review-g33357928-d33352143-Reviews-Chipoma_Falls-Chimbele_Muchinga_Province.html). The site should confirm image reuse permission before production launch.

Gallery descriptions and place names are grounded in the [Chinsali Municipal Council tourism and cultural heritage overview](https://www.chinsalicouncil.gov.zm/?page_id=118), which identifies Lubwa Mission Church, Chipoma Water Falls and heritage linked to Chinsali's political and spiritual history.

The editorial photographs are presented with source links in the site credit line. Replace them with council-owned or explicitly licensed photographs before public production deployment if permission is not confirmed.
