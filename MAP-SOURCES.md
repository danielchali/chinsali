# Chinsali landmark map sources

The gallery map uses Leaflet with OpenStreetMap tiles. OpenStreetMap attribution is shown directly on the map and tile requests are made only for the visitor's active viewport.

- **Chinsali town / market reference:** `-10.5499720, 32.0660837`, from [Nominatim search for Chinsali, Zambia](https://nominatim.openstreetmap.org/ui/search.html?q=Chinsali%2C%20Zambia). The public geocoder did not return a distinct Chinsali New Market feature, so the market photograph is labelled as a town-centre reference rather than an exact market entrance.
- **Lubwa Mission:** `-10.58987, 32.00819`, from [Mindat's Lubwa Mission locality record](https://www.mindat.org/feature-909723.html). The map label describes this as a public locality coordinate, not a surveyed building entrance.
- **Chipoma Falls:** `-10.75015, 32.00461`, from [Mapcarta's Chipoma Falls record](https://mapcarta.com/14182890), which also links the corresponding OpenStreetMap feature.

Place descriptions are grounded in the [Chinsali Municipal Council tourism and cultural heritage overview](https://www.chinsalicouncil.gov.zm/?page_id=118). Coordinates should be checked against current local signage or council data before being used for navigation, emergency response or official surveying.
